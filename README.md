# Beatscope

[![Release](https://img.shields.io/github/v/release/Anchovia/beatscope)](https://github.com/Anchovia/beatscope/releases/latest)
[![Downloads](https://img.shields.io/github/downloads/Anchovia/beatscope/total)](https://github.com/Anchovia/beatscope/releases)

**DJMAX RESPECT V용 비공식 플레이 분석 도구입니다.**

키 입력을 기록하고, 플레이가 끝나면 악곡과 버튼 모드를 자동으로 찾아 리플레이와 노트별 FAST/SLOW 분석을 제공합니다. OBS용 키뷰어와 실시간 판정 오버레이도 지원합니다.

현재 배포 버전은 **Beatscope v0.1.0 테스트 버전**입니다. 분석 결과에 오차가 있거나 버그가 발생할 수 있습니다.

[다운로드](https://github.com/Anchovia/beatscope/releases/latest) · [오류 제보·개선 의견](https://github.com/Anchovia/beatscope/issues)

## 주요 기능

- 입력 기록을 이용한 악곡·버튼 모드 자동 인식
- 채보 위에 내 입력을 겹쳐 보는 리플레이
- 노트별 FAST/SLOW 시차와 판정 분포 분석
- 레인별 평균과 자주 어긋나는 구간 확인
- 악곡별 플레이 기록, 노트 밀도, KPS, 패턴 정보
- OBS 키뷰어: 입력 횟수, KPS, 키 이름, 결과 카드 표시
- OBS 실시간 FAST/SLOW 판정 오버레이
- 블럭·서클 노트 디자인과 사이드·트리거 색상 설정

## 지원 환경과 버튼

- Windows 10/11, 64비트
- 키뷰어·OBS 오버레이: **4B·5B·6B·8B**
- 악곡 자동 인식·리플레이 분석: 현재 포함된 **4B·6B·8B 채보** 기준

5B 채보 묶음은 아직 포함되지 않았습니다. 모든 악곡·난이도의 분석을 지원하는 것은 아니며, 채보가 없거나 인식이 불확실하면 악곡 확인이 필요할 수 있습니다. 검증되지 않은 채보의 구간은 앱에서 별도로 표시하거나 판정 시차 표시를 제한합니다.

OBS의 버튼 선택은 키뷰어에 사용할 키 배치를 정합니다. 기록 분석의 버튼 모드는 보유 채보와 입력 기록을 대조해 인식하며, 필요한 경우 결과 화면의 **악곡 · 버튼 변경**에서 직접 선택할 수 있습니다.

## 다운로드와 실행

1. [Releases](https://github.com/Anchovia/beatscope/releases/latest)에서 **Beatscope.exe**를 다운로드합니다.
2. 다운로드한 실행 파일을 실행합니다. 별도 설치 프로그램은 사용하지 않습니다.
3. **키 설정** 탭에서 사용하는 버튼 모드의 키 배치를 설정합니다.

공개 배포 파일을 실행하는 데 Rust나 Node.js는 필요하지 않습니다.

코드 서명을 하지 않은 실행 파일이므로 Windows에서 실행 경고가 표시될 수 있습니다. 공식 배포 주소와 다운로드한 파일을 확인한 뒤 실행 여부를 판단해 주세요.

설정과 기록은 `%APPDATA%\max-scouter`에 저장됩니다. 업데이트할 때 이 폴더를 지우지 않고 새 실행 파일을 사용하면 기존 데이터를 유지할 수 있습니다.

## 사용 방법

### 플레이 기록과 리플레이

1. **키 설정** 탭에서 실제 게임의 키 배치를 설정합니다. 여러 버튼 모드를 사용한다면 각각 설정해 주세요.
2. **플레이** 탭에서 **기록 켜기**를 누릅니다. 앱을 실행할 때 기록은 기본적으로 꺼져 있습니다.
3. 게임을 플레이합니다. 플레이가 끝나고 일정 시간 입력이 없으면 기록이 저장됩니다.
4. **결과** 탭에서 기록을 열어 리플레이와 분석 결과를 확인합니다.
5. 악곡이나 버튼 모드가 잘못 선택됐거나 확인이 필요하면 **악곡 · 버튼 변경**에서 수정합니다.

악곡별 기록과 채보 정보는 **악곡** 탭에서 확인할 수 있습니다.

### 화면 기반 판정

실시간 판정과 리플레이의 화면 기준 보정을 사용하려면 **설정 > 판정**에서 화면 읽기를 켜고, **설정 > 게임 옵션**의 값을 실제 게임 설정과 맞춰 주세요.

- 게임 판정 타이밍 값
- 기어 위치
- 사이드 노트 색상
- L & R 노트 색상(8B)

화면 읽기는 게임 창이 맨 앞에 있을 때 동작합니다. 권장 게임 설정은 앱의 안내를 확인해 주세요. 기어 투명도·BGA·화면 효과·해상도 등 환경에 따라 인식 결과가 달라질 수 있습니다.

### OBS 키뷰어

1. **오버레이** 탭에서 OBS 오버레이를 켭니다.
2. 오른쪽 **보기** 패널에서 사용할 버튼 모드를 선택합니다.
3. **주소 복사**를 누르고 OBS의 **브라우저 소스**에 URL을 붙여 넣습니다.
4. 브라우저 소스 크기를 **너비 400, 높이 600**으로 설정합니다.

노트 디자인, 색상, 속도, 진하기와 표시 항목은 **보기** 패널에서 조절합니다. 결과 카드와 최고 기록 비교 표시는 기본적으로 꺼져 있으며 필요할 때 켤 수 있습니다.

## 작동 방식과 사용 안내

판정 분석에는 Windows의 키 입력과 화면 캡처를 사용합니다. 게임 메모리·파일에 접근하거나 게임에 코드를 주입하지 않으며, 자동 입력이나 게임 판정·점수를 변경하는 기능도 없습니다.

Beatscope는 **NEOWIZ의 공식 사용 허가를 받은 도구가 아닙니다.** 게임에 직접 개입하지 않는 방식으로 구현했지만, 이용약관 및 운영 정책에 따른 허용 여부나 제재 가능성을 보장하지는 않습니다.

## 테스트 결과와 한계

- 기존 **단일 곡 테스트**에서 실시간 오버레이와 리플레이의 FAST/SLOW 방향은 약 **95% 일치**했습니다.
- 별도 플레이 테스트에서 두 판정 시차의 절댓값 **95백분위**는 판별로 약 **1.8~2.3ms**였습니다.

위 수치는 **두 분석 방식 사이의 비교 결과**입니다. 실제 게임 판정 대비 정확도나 리플레이 전체의 오차 범위를 보장하는 값은 아닙니다. 인식 상태에 따라 더 큰 차이 또는 부정확한 결과가 발생할 수 있습니다.

채보 검증, 화면 기준 보정, 실제 게임 판정과의 대조는 서로 다른 검증입니다. 분석 수치는 연습을 위한 참고 자료로 사용해 주세요.

앞으로 플레이 데이터 분석과 업데이트를 통해 기능과 판정 정확도를 꾸준히 개선해 나가겠습니다.

## 오류 제보와 개선 의견

[GitHub Issues](https://github.com/Anchovia/beatscope/issues)에 남겨 주세요. 가능하면 다음 내용을 함께 적어 주시면 확인에 도움이 됩니다.

- Beatscope 버전과 Windows 버전
- 악곡·버튼 모드·난이도
- 문제가 발생한 상황과 재현 순서
- 관련 화면이나 오류 메시지

앱의 **설정 > 정보 > 문제 해결**에서 진단 정보를 저장할 수 있습니다. 진단 정보에는 키 입력 기록을 포함하지 않습니다. 진단 파일이나 플레이 기록을 공개로 첨부하기 전에는 내용을 확인해 주세요.

사용한 오픈소스 구성 요소의 라이선스와 원문은 앱의 **설정 > 정보 > 오픈소스 라이선스**에서 확인할 수 있습니다.

이 저장소는 실행 파일 배포와 오류 제보를 위한 저장소이며, 프로그램 소스 코드는 공개하지 않습니다.
